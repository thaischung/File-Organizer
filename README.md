This program cleans out a user specified directory and organizes different file types into seperate folders based of of their extension. 

To run this on Windows: 
    0. Download the python file
    1. Open the python file and at the top fill in the paths at the top 
    2. Download python if not already installed 
        - you can check if you have python by using: python3 --version
    3. Download pip


To run this on MAC/Linux
    0. Download the python file
    1. Create a folder for you python file
    2. Move the file into that folder
    3. Open the python file and at the top fill in the paths at the top 
    4. Download python if not already installed 
        - you can check if you have python by using: python3 --version
    5. Download pip: python3 -m pip install 
    6. Check that the download was successful by using: pip --version 
    7. Navigate to your folder
        Use: pwd
            copy and past the result
        Use: cd copy_pasted_result/folder_name
    8. Create the vitual environemnt: python3 -m venv venv
    9. Activate our virtual environment: source venv/bin/activate 
    10. Download the watchdog module: pip install watchdog
    11. Now you can run your script: python3 folderCleaner.py
        to stop the program: ctrl + c
